# BND Fan ID Maker

A Vercel-ready Next.js fan project for creating a customizable BOYNEXTDOOR-inspired digital ID.

## Features

- Name / nickname
- Favorite member
- Birthday
- Favorite song
- Custom card color
- Profile photo
- Generated fan ID number
- Saves the current design in localStorage
- Responsive/mobile-friendly layout
- No database or API keys required

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Deploy to Vercel

1. Create a GitHub repository.
2. Upload this project.
3. Import the repository into Vercel.
4. Vercel will detect Next.js automatically.
5. Deploy.

## Important

This is a fan-made project. It is not an official BOYNEXTDOOR or KOZ Entertainment membership card/site. Avoid using official logos or implying official membership status.

The profile photo is stored in the browser's localStorage for this demo. A production version should use a proper storage/database service if users need shareable accounts or permanent public IDs.
